# Button Tap Me!

A simple iOS app built with SwiftUI as part of the **100 Days with SwiftUI** challenge.

## Overview

**Button Tap Me!** (Xcode project name: *StringWork*) is a SwiftUI-based iOS application that demonstrates basic UI interactions. The app displays a greeting and is designed to be extended with button tap functionality.

## Requirements

- **iOS** 13.0 or later
- **Xcode** 11.0 or later
- **Swift** 5.0 or later

## Project Structure

```
Button-Tap-me-/
├── StringWork/                  # Main app source files
│   ├── AppDelegate.swift        # Application lifecycle management
│   ├── SceneDelegate.swift      # Scene lifecycle management
│   ├── ContentView.swift        # Main SwiftUI view
│   ├── Assets.xcassets/         # Image and color assets
│   ├── Base.lproj/              # Storyboard and localization resources
│   └── Info.plist               # App configuration
├── StringWork.xcodeproj/        # Xcode project file
├── StringWorkTests/             # Unit tests
│   └── StringWorkTests.swift
└── StringWorkUITests/           # UI tests
    └── StringWorkUITests.swift
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/pstoenchev/Button-Tap-me-.git
   ```

2. Open the project in Xcode:
   ```bash
   open StringWork.xcodeproj
   ```

3. Select a simulator or connected device and press **Run** (⌘R).

## Running Tests

To run the unit and UI tests, press **⌘U** in Xcode or navigate to **Product → Test**.
